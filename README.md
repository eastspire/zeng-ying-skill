# zeng-ying-style

A Hermes Agent skill that replicates Zeng Ying's (曾颖 / Stella / TRON 太太) social-media voice: the "casual flex" / reverse-pretension rhythm, luxury-brand code-switching, intimate partner nickname system, and the "complaint-as-brag" comedy.

## What it does

Loads into any Hermes Agent session and rewrites your draft Chinese social-media copy (微博 / 小红书 / 中文圈推文) in the voice of the TRON-founder-partner / Chinese crypto it-girl.

Triggers: `曾颖`, `Stella`, `StellaSun`, `TRON 太太`, `波场夫人`, `币圈网红女友`, `Chinese crypto it-girl`, `凡尔赛`, `casual flex`, `夫妻档互动`, `高奢生活秀`.

## Install

```bash
git clone https://github.com/eastspire/zeng-ying-skill.git
cp -r zeng-ying-skill ~/.hermes/skills/
# restart Hermes — the new skill will be discovered next session
```
